# Vue 调色视图

电脑端相册里的调色工作区。调色引擎仍是现有的 `src/grade/document.rs`、`src/grade/exec.rs`、`src/grade/color.rs`：内存文档、整节点参数替换、只重跑下游。本文只定界面和宿主接口，不改节点公式。调色配置是原片旁边的 `.lumeno.json`，不是 XMP。

管线语义以 `docs/color-pipeline.md` 为准。分组、直方图和列表只存在于前端。

## 范围

只做电脑端。手机相册不出现这个入口。

沿用现在已经能跑的节点：Input、WhiteBalance、Demosaic、Input Color Profile、Exposure、LocalContrast、Dehaze、Velvia、Denoise、Sharpen、Rotate、Crop、Sigmoid、Export。RAW 才有白平衡、去马赛克和输入色彩配置。

不做：

- 把调色写进 XMP。管线成功之后，把节点参数写到原片旁边的 `{文件名}.lumeno.json`。原片和 XMP 不改。只读分享不写这份文件。再次打开同一张照片时先读它，再套到这次解码出来的文档上
- 预设库
- 编辑连线，或增加 Blend、掩码节点
- 手机壳里的调色视图
- 改浏览详情里的下载、导出、安全区和手势

## 入口

相册顶栏「视图设置」弹出层（`frontend/src/components/AlbumPanel.vue` 里 `thumbnailPopoverOpen`，约 2533–2599 行）在「详细信息 / 仅缩略图」下面加一项「调色视图」。只在非 `isMobile` 时显示。

点下去关掉弹出层，相册内容区从照片网格换成调色工作区。顶栏留着，方便再打开视图设置回到浏览。同一项再点一次，或工作区里的返回，回到进入前的网格，并记住当时的滚动和筛选。

当前照片：若详情已打开，用那张；否则用当前列表第一张可调色的图。视频不能进调色，底栏里灰掉。

## 工作区

顶栏以下铺满。调色时这条顶栏只留「返回浏览」，资源按钮在同一栏的最右边，不放在浏览网格那条顶栏上。资源窗口和 AI 工具窗口同一尺寸。顶栏下面四块：

```text
+------------------+---------------------------+------------------+
| 左侧信息         | 中间预览                  | 右侧工具         |
|                  |                           | 直方图           |
|                  |                           | 分组按钮         |
|                  |                           | 节点列表         |
+------------------+---------------------------+------------------+
| 底部横向胶片条                                                  |
+-----------------------------------------------------------------+
```

- 左栏宽约 18rem，进入调色时展开，可以收起。可滚动。顶部是当前预览的小图，下面与浏览里点开照片后的右侧信息栏相同：文件名、日期、相机、镜头、焦距、光圈、快门、ISO、大小、尺寸、下载、导出、星级、色标、标签、设为封面、加入相册、找相似、删除、保存。放大超过适配范围时，可见范围画在这张小图上，拖动小图平移画面。实现上把 `AlbumPanel.vue` 约 3401–3501 行抽成共用组件，详情浮层和调色左栏各用一次，避免两份表单。
- 中间是调色预览，`object-contain`，铺在左栏和右栏之间、胶片条之上。换图或参数计算中时保留上一帧，画面不压暗。左上角圆点：小图请求未完成是黄的，小图已经换上、全尺寸还没回来是灰的，全尺寸预览换上之后圆点消失。预览响应带 `view.degrees` 和 `view.roi`。画面按这个变换显示，平时只露出选区。展开旋转时露出整块旋转画布，并画出选区，框外变暗。
- 预览和底部胶片之间有一条细栏。第一个按钮是开灯：按下后照片四周加一圈白边，用来判断曝光。再按关掉。白边跟着画面变大，碰到视口边缘后停住，不再被放大推出去；继续缩放只放大白边里面的照片。不开灯时，放大不受最初适配区域限制，可以铺满视口。栏中间有一个拖动手柄，按住上下拖可以改变底部胶片的高度，格子跟着变高变矮。
- 底部一条横向胶片，可横向滚，用虚拟列表，只挂视口附近的格子。每张图用和浏览格子相同的缩略图请求（`/api/thumbnail`，长边 360）。滚到临近尽头时继续加载下一页，和浏览网格同一条加载。数据用当前相册列表，含现有筛选和排序。当前项高亮。点一张就切换调色文档。
- 右栏宽约 20rem。上直方图，下节点列表。背景偏深，控件紧，不使用大圆角卡片。

## 直方图

用叠在一起的红、绿、蓝直方图，不用波形图。预览图解码后在浏览器里统计 R/G/B，三条半透明填充曲线放在同一坐标上。底部一行小字：`ISO {iso} · {焦距} · {光圈} · {快门}`，缺的字段省掉。没有预览时留空底。不为此加后端接口。

## 节点行

一类里面按管线顺序排。每一行是一条扁的工具条，大约 28–32px，左右留白小，行与行之间 2px。不要圆角矩形卡片。一行从左到右：

- 开关：圆形电源图标。开为实心，关为描边。关的节点仍留在所属分组里，只是不进「当前打开」。
- 名称：左对齐，单行省略。
- 恢复默认：把该节点参数设回 `default_kind`，开关状态不动。
- 选项：最右的菜单图标。现在没有预设，菜单里只写「暂无预设」。按钮仍然占位，和 darktable 的预设菜单同一位置。

点名称或行的空白处，在该行正下方展开参数。同一分组里同时只展开一个。再点收起。展开区背景只比列表深一点。滑杆用现有 `AppSlider`，选择用分段小按钮，开关用现有 `app-switch`。标签和数值同一行，参数名按文字宽度显示，不截断；只读的值过长才省略。垂直间距约 8px。只读字段只显示文字。

参数定义沿用 `document::fields()`。白平衡在「色温」或「通道增益」时才多出对应滑杆。改任何一个字段，都把该节点当前全部参数一次提交，不发增量字段。

各节点字段：

| 节点 | 字段 |
| --- | --- |
| input | 来源，只读 |
| white-balance | 模式：相机白平衡 / 色温 / 通道增益。色温模式再给色温、色调。增益模式再给 R、G、B |

| crop | X、Y、宽度、高度 |
| export | 格式、质量、长边。预览忽略这三项 |
| exposure | 曝光、黑电平 |

## 和后端的衔接

`color`、`document`、`exec` 不改语义。一次打开在内存里留一份文档和预览缓存。同一个登录可以同时留着多次打开，每次有自己的 `rev`。改节点和全尺寸预览都带上这次的 `rev`，并且这次打开必须属于这个登录。再打开一张照片不会拆掉已经打开的那次。内存里最多留 16 次，更早的被丢掉；丢掉之后界面重新打开当前这张照片，不把旧请求的失败句子显示出来。全尺寸预览算到一半又改了参数时，那次全尺寸结果直接丢掉，不报「调色已经换过」。

`POST /api/grade/open`

请求：路径，以及可选的 owner。服务端解码出文档需要的相机信息，调用 `default_document`，先返回节点列表，不算预览。响应：`rev` 和节点。每个节点带 id、enabled、always_on、标题、参数和字段。分组由前端按上一节计算。节点列表不等预览图。

`POST /api/grade/preview`

请求：`{ rev }`。用这次打开时已经解码的小图跑管线，返回预览和 `view`。界面在节点列表到了之后再发。若这期间参数又改过，响应是 `superseded`，不带预览，避免旧图盖住新参数。

`POST /api/grade/node`

请求：`{ id, enabled, params }`。服务端 `apply_node_params`。参数和这次打开时不同，节点改成打开；参数没变时才按请求里的 `enabled`。会话只保留进入这次改动节点的那一帧。再改同一个节点时从这一帧算起，不重跑它的上游。改到另一个节点时，换成进入那个节点的帧。响应：更新后的该节点字段，以及新预览。

滑杆拖动时前端合并请求，停顿后再发一次。新的一次会取消还在进行的预览请求，后返回的旧结果不采用。切换照片时同样取消未完成的预览。

同一次打开里，小预览和全尺寸互不打断。改节点会停掉正在跑的小预览、改节点和全尺寸。新的全尺寸会停掉还在跑的改节点和上一次全尺寸。被停掉的那次返回 `superseded`，不写预览缓存。

`open` 只带节点。`preview`、`node`、`full` 的响应在有图时带 `view`：`degrees` 是叠加上的旋转，`roi` 是变换后画布上的归一化选区。几何节点只写这两项，不改像素。

导出节点的格式和质量存在文档里。预览仍忽略它们，和现在的 `exec` 一致。左栏「导出」继续走现有相册导出，不从调色会话出文件。
